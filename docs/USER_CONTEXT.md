# Contexto persistente del usuario y protocolo de continuidad

## Restricción de acceso a ChatGPT

- El usuario utiliza ChatGPT Free desde Android.
- Ha explicado repetidamente que alcanza límites de uso: la conversación/sesión deja de estar disponible durante un tiempo y, según su experiencia, debe esperar hasta 24 horas para volver a utilizarlo.
- Este límite hace que no pueda reconstruir el contexto manualmente cada vez que cambia de chat o se restablece el acceso.
- No pedirle que repita información que ya conste en este documento, en Notion o en el historial del proyecto.
- No confundir esta experiencia individual con una garantía universal sobre los límites de todos los usuarios Free: los límites pueden variar por modelo, carga y producto y deben comprobarse en la interfaz vigente.

## Protocolo obligatorio para cualquier IA que continúe AI-EMPIRE

1. Leer primero este archivo y `README.md`.
2. Consultar en Notion:
   - AI-EMPIRE / JARVIS — Continuidad y estado del proyecto.
   - JARVIS — Memoria Maestra.
   - JARVIS CORE — Índice técnico.
3. Revisar los archivos y commits actuales de este repositorio antes de proponer cambios.
4. Resumir internamente qué está confirmado, qué está pendiente y qué se ha cambiado recientemente.
5. No pedir al usuario que vuelva a explicar objetivos, presupuesto, dispositivo, restricciones, arquitectura o decisiones ya documentadas.
6. Hacer una sola pregunta concreta solo si falta un dato imprescindible o existe una decisión nueva.
7. Mantener Notion como fuente de verdad de decisiones y continuidad; GitHub como fuente de verdad del código.
8. Mantener un registro de los cambios y de sus evidencias. No declarar una función VERIFICADA sin una prueba reproducible.
9. Trabajar paso a paso en comandos completos de Termux, evitando errores de copiar código Python directamente en Bash.
10. No instalar paquetes, gastar dinero, publicar contenido ni ejecutar acciones externas sin la autorización correspondiente.
